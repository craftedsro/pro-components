# eShop - PC 笔记本电脑商城

这是一个使用 ProComponents 构建的完整电子商务示例应用，展示了如何创建一个销售 PC 笔记本电脑的在线商店。

## 功能特性

- **产品列表**: 使用 ProTable 展示所有可用的笔记本电脑产品，支持搜索、筛选和排序
- **产品详情**: 使用 ProDescriptions 展示详细的产品规格信息
- **购物车**: 实时购物车管理，支持添加、删除商品
- **结账流程**: 使用 ProForm 创建完整的结账表单，包括配送信息和支付信息
- **库存管理**: 实时显示产品库存状态
- **价格计算**: 自动计算购物车总价

## 技术亮点

本示例展示了以下 ProComponents 组件的使用：

- **ProTable**: 用于展示产品列表，支持高级搜索和筛选功能
- **ProDescriptions**: 用于展示产品详细信息
- **ProForm**: 用于创建结账表单
- **ProCard**: 用于组织页面布局

## 使用场景

此示例适用于：

- 电子商务应用开发
- 产品目录管理
- 在线商店建设
- B2C 电子商务平台
