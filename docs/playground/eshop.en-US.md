# eShop - PC Notebook Store

This is a complete e-commerce example application built with ProComponents, demonstrating how to create an online store for selling PC notebooks.

## Features

- **Product Listing**: Display all available notebook products using ProTable with search, filter, and sort capabilities
- **Product Details**: Show detailed product specifications using ProDescriptions
- **Shopping Cart**: Real-time shopping cart management with add and remove functionality
- **Checkout Process**: Complete checkout form created with ProForm, including shipping and payment information
- **Inventory Management**: Real-time product stock status display
- **Price Calculation**: Automatic shopping cart total calculation

## Technical Highlights

This example demonstrates the usage of the following ProComponents:

- **ProTable**: For displaying product listings with advanced search and filter features
- **ProDescriptions**: For showing detailed product information
- **ProForm**: For creating the checkout form
- **ProCard**: For organizing page layout

## Use Cases

This example is suitable for:

- E-commerce application development
- Product catalog management
- Online store construction
- B2C e-commerce platforms
